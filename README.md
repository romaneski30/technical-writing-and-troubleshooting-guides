# Technical Writing & Troubleshooting Guides

AI-assisted technical articles, diagrams, and troubleshooting resources.

## Featured learning sample

### Management, Out-of-Band Access & Packet Forwarding

[Read the interactive HTML article](docs/oob-management-forwarding.html)

Learn how a hardware-management controller, network-OS control processor, and packet-forwarding ASIC perform different jobs—and why a response from one is not a health verdict for the others.

- Functional data-flow diagrams with desktop and mobile layouts.
- General troubleshooting scenarios that separate evidence from assumptions.
- Six expandable knowledge checks.
- Public references and platform-specific limitations.

**Viewing:** GitHub shows HTML source rather than running the page. Download `docs/oob-management-forwarding.html` and open it locally in a browser. It is self-contained: no JavaScript, external images, fonts, analytics, storage, or backend. A hosted preview can be added later; it is not configured by this package.

## Project contribution

I identified the learning need, shaped the questions, and refined the explanation through practical feedback. AI assisted with drafting, HTML/CSS implementation, and structured verification. The goal is to demonstrate how I work with AI to make technical information understandable and useful—not to claim independent authorship of every line.

## Scope

This repository contains standalone educational examples based on general concepts and public references. The diagrams and troubleshooting scenarios are illustrative, not records of a real deployment. Architecture, hardware serviceability, and failure behavior vary by platform; use the applicable vendor documentation and authorized procedures for real equipment.

Future writing and guidance projects can be added as they are developed. They are not included or represented as completed tools in this initial sample.
